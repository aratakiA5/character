# Character Creator

ブラウザで動作するシンプルなキャラクタークリエイトです。

## 現在の機能

- 名前、種族、職業、性格の設定
- 筋力・体力・器用・知力・精神・幸運の能力値設定
- 能力値合計60ポイント制
- 外見・設定メモ
- リアルタイムプレビュー
- ランダムキャラクター作成
- localStorageへのキャラクター保存
- 保存キャラクターの削除

## 起動方法

`index.html` をブラウザで開くだけで動作します。
